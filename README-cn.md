# [Nexus Blog](https://lvyuemeng.github.io/Nexus-Blog/)

这是一个基于 [Hugo](https://gohugo.io/) 和 [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 主题构建的静态博客平台。

如果你想分享一些东西，可以查看**贡献指南**！

## 贡献指南

欢迎漏洞报告、代码贡献和分支。所有其他形式的讨论都在 [Discussions](https://github.com/lvyuemeng/Nexus-Blog/discussions) 进行。

在 [贡献指南](./CONTRIBUTION.md) 中查看更多信息!
